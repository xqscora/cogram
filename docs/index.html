Evidence and cost scope

The counter reports a characters/4 estimate of the current source payload beside the estimated size of the entire source corpus. It is not a measured per-query saving. In the separate historical LongMemEval run below, Cogram+BM25 used 1,992 context tokens per question versus 89,469 in a mixed-cap full-context arm. Answer-model calls still have a cost; this page does not establish annual savings or production latency.

Path to adoption

Available: the Python memory core and a static browser export under CC BY-NC-SA. Proposed: agent adapters and shared team memory. Repository sync code is not evidence of a tested hosted service, production readiness, paying customers, or a commercial license.

Where this is strong, where it isn't

Pros
  • Graph construction and retrieval use zero LLM calls. Returned text comes from source records; it can still be irrelevant, incomplete, or wrong.
  • Forgetting has a floor, not a cliff — edges decay toward ε but are never deleted, and get re-lit the moment they're relevant again.
  • Decay runs on ticks (real interactions), not wall-clock days — an idle agent's memory doesn't erode just because time passed.
  • Every recall points to an exact file:line in the original transcript — never a generated summary, always checkable.
  • The browser counter is a heuristic, not a tokenizer measurement; display excerpts may be truncated while the payload estimate uses their full text.
  • The historical Python routing report records 43.3% top-1 same-repo recall on 150 sampled reports (31 distinct issues). It is not held-out fix success or a score for this browser revision. Method and limitations.
Cons — said plainly
  • Not the first zero-LLM concept-graph memory — SPRIG (arXiv:2602.23372) and MemGraph-agent already proved this general approach works.
  • On LongMemEval, our graph's ranking ties the best lexical baseline (BM25) rather than beating it outright — see appendix below.
  • It can only recall what the agent actually lived through — no prior trajectory, no memory of it.
  • Motif mining is separate from this browser's live retrieval and must not be credited with improving its results.
  • Directed "next" transitions are still a first-order heuristic — the precision benchmark validates which line gets recalled, not yet whether the "next step" ordering itself is correct.
